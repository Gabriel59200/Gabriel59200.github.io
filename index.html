Max Simulator.

Un simulateur inspiré d’iOS : ouvre les applications, modifie les réglages, installe ou supprime des apps, masque des icônes, configure un code et joue à un mini-jeu. Les changements sont enregistrés dans ce navigateur.

Limite honnête : aucun site ne peut installer ou exécuter toutes les applications iOS natives ni reproduire tous les services Apple. Ici, les applications intégrées et les mini-apps sont de vraies fonctions JavaScript dans la maquette. Pour la compatibilité avec des apps tierces, il faudrait développer chaque app ou la connecter à un service web compatible.
